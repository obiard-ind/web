# Prérequis : création de la DB
Dans cette seconde remise, vous enregistrerez vos données dans une base de données.
Le prérequis est donc de bien lire le document qui vous a été transmis, de modéliser et d'implémenter une base de données pouvant contenir les données que vous y insérerez.

**Aide** : votre base de données contiendra 2 tables : une table `utilisateurs` et une table `taches` reliées entre elles.
# Authentification
Créer une route qui, au départ de `/`, affichera un formulaire de login.
Créer une route qui, au départ de `/register` affichera un formulaire d'enregistrement.
Créer une route qui, au départ de `/login` validera l'authentification de l'utilisateur.

Dans `/register`, distinguez deux cas :
- le cas où vous affichez le formulaire d'enregistrement;
- et le cas ou vous recevez et traitez les données du formulaire.  

Dans `/login`, distinguez deux cas :
- le cas où vous affichez le formulaire de login,
- et le cas où vous recevez et traitez les données du formulaire.
